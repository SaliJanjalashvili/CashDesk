# CashDesk - Modern Banking Dashboard

A responsive, feature-rich banking dashboard built with pure HTML and CSS. This project showcases modern web design principles, accessibility features, and responsive layouts without using any JavaScript or CSS frameworks.

## 🌟 Features

### Core Functionality

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark/Light Theme Toggle** - Pure CSS theme switching with smooth transitions
- **Account Management** - Multiple account types (Checking, Savings, Credit)
- **Transaction History** - Detailed transaction listings with filtering and search
- **Spending Analytics** - Visual spending breakdown with progress indicators
- **Modern UI Components** - Cards, buttons, forms, and navigation elements

### Design Highlights

- **Clean, Modern Interface** - Inspired by contemporary banking apps
- **Consistent Design System** - Unified color scheme, typography, and spacing
- **Smooth Animations** - Hover effects, transitions, and micro-interactions
- **Accessibility First** - Proper contrast ratios, focus states, and semantic HTML
- **Mobile-First Approach** - Optimized for all screen sizes

## 📱 Pages

### 1. Dashboard (`index.html`)

- **Welcome Section** - Personalized greeting and overview
- **Quick Stats** - Total balance, income, expenses, and savings goal
- **Account Cards** - Primary checking, savings, and credit accounts
- **Spending Visualization** - Circular progress chart showing budget usage
- **Category Breakdown** - Detailed spending by category with progress bars
- **Recent Transactions** - Latest financial activity

### 2. Transactions (`transactions.html`)

- **Transaction Summary** - Monthly income, expenses, and net change
- **Advanced Filtering** - Date range, type, and category filters
- **Search Functionality** - Find specific transactions quickly
- **Grouped Transactions** - Organized by date with daily totals
- **Detailed Information** - Transaction name, category, time, and amount

## 🎨 Design System

### Color Palette

- **Primary**: Indigo (#6366f1) - Main brand color
- **Secondary**: Purple (#8b5cf6) - Accent color
- **Success**: Green (#10b981) - Positive values
- **Warning**: Amber (#f59e0b) - Alerts
- **Error**: Red (#ef4444) - Negative values

### Typography

- **Font Family**: Inter (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700, 800
- **Responsive Sizing**: Scales appropriately across devices

### Spacing System

- **Consistent Scale**: 0.25rem to 3rem increments
- **Responsive Padding**: Adjusts based on screen size
- **Proper Hierarchy**: Clear visual relationships

## 🔧 Technical Implementation

### CSS Architecture

- **CSS Variables** - Centralized theming system
- **Modular Structure** - Organized by components and sections
- **BEM Methodology** - Consistent naming conventions
- **Responsive Grid** - CSS Grid and Flexbox layouts

### Theme System

- **CSS-Only Toggle** - No JavaScript required
- **Smooth Transitions** - Animated theme switching
- **Comprehensive Coverage** - All components support both themes
- **System Preference** - Respects user's OS theme preference

### Responsive Breakpoints

- **Mobile**: < 480px
- **Tablet**: 480px - 768px
- **Desktop**: > 768px

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Navigate** between pages using the navigation menu
4. **Toggle** between light and dark themes using the theme switch
